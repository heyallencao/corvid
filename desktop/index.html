导入浏览器资料

从本机 Google Chrome 导入书签和浏览历史；macOS 也支持 Cookie 登录状态。扩展和已保存密码暂不支持。
BROWSER DATA

从 Google Chrome 导入

建议先退出 Chrome，确保历史资料完整。这里只读取你选择的本机资料，不改动源文件，也不会上传。

选择目录后会显示可导入项目数量。
选择要导入的资料

勾选 Cookie 会通过 macOS 钥匙串读取 Chrome 加密密钥；只迁移 Cookie，不迁移已保存密码。分区或不支持的 Cookie 会计为未导入。书签文件夹会展平，扩展暂不支持。
WELCOME TO CORVID

从 Chrome 开始使用 Corvid？

可以把书签和浏览历史带到 Corvid；macOS 还可选择导入 Cookie 登录状态。开始前会让你选择 Chrome 资料和导入内容。

扩展和已保存密码暂不支持导入。你也可以稍后在设置中再导入。
