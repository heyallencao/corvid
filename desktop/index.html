从 Google Chrome 导入

选择要导入的资料

导入 Cookie 会读取 macOS 钥匙串

确认导入后，Corvid 会请求访问“Chrome Safe Storage”以解密所选 Chrome Profile 的 Cookie。macOS 可能显示钥匙串授权提示；拒绝授权或取消导入都不会写入 Cookie。Cookie 只保存到上方指定的 Corvid Profile，不会上传。

扩展代码会在目标 Corvid Profile 中运行。请核对每个扩展的权限；Electron 只支持部分 Chrome 扩展 API，扩展工具栏弹窗暂未集成；导入后可能无法使用，已打开的页面需要重新加载。扩展设置与已保存密码不会迁移。Cookie 导入仅支持 macOS；会话 Cookie 会在 Corvid 退出时按源语义失效，带有效期的 Cookie 可跨重启保留。
WELCOME TO CORVID

从 Chrome 开始使用 Corvid？

你可以选择迁移书签、历史记录、Cookie 登录状态和兼容的扩展。开始前会让你选择 Chrome 资料与导入内容。

扩展只支持 Electron 可运行的部分 Chrome API；已保存密码不会导入。你也可以稍后在设置中再导入。
