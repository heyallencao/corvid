# Issue #165 D25-2：macOS 原生下载对话框

## 验收范围

2026-11-06 在 macOS 26.5.1 arm64、Node.js v24.22.1、Electron 45.2.1 开发版中，以独立 worktree 和临时 `CORVID_DATA_DIR` 手动验收设置中心的下载目录选择器与下载保存位置对话框。测试未访问真实网站、用户浏览资料、模型、Provider 或 OAuth。

## 直接观察

- 设置中心“更改文件夹”分别在英文和简体中文界面打开 macOS 原生目录选择器，标题对应为 “Choose download folder” 与“选择下载文件夹”。取消后设置表单中的目录路径保持原值。
- 在隔离目录中选择合成目标文件夹后，设置字段更新为该路径；点击“保存设置”后，`browser-preferences.json` 中的 `downloadDirectory` 更新，文件权限为 `0600`。关闭并重启 Corvid 后，语言与所选下载目录均恢复。
- 开启“下载前询问保存位置”后，通过本地 `file://` 合成页面下载文本夹具，系统保存对话框分别显示 “Save download” 与“保存下载”。取消两种语言下的保存均未在目标目录创建文件；确认后只在隔离目标目录写入预期合成内容。
- 首次从空白下载目录设置打开选择器时，系统默认位置指向主机 Downloads。发现选择器可枚举主机目录项后立即取消；没有打开条目、复制或处理目录中的文件，也没有保留该次选择器截图。后续确认和下载均使用隔离目录。

## 覆盖限制

本记录仅证明 macOS 26.5.1 arm64 开发版下的原生目录选择、下载保存取消/确认和偏好重启恢复。没有验证 Windows、签名打包版、VoiceOver、其它原生确认框或像素级布局；自动化测试仍用替身覆盖目录与保存对话框。截图未留存：系统选择器的目录列表会显示宿主机文件系统内容，不适合作为可分享的隔离截图。
