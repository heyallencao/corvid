## Release summary / English

Corvid is a local-first desktop browser with a built-in Agent workspace and external SDK/CLI. This draft is not published. The current source snapshot has no packaged desktop installer, and its full Electron regression has not passed consistently. Platform packaging, signing, notarization, installation, upgrade, and uninstall remain unverified.
