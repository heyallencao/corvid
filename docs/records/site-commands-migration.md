# 只读站点命令存储说明

Issue #341 新增独立的 `site-commands.json`，schema 为 `version: 1`。此前版本没有站点命令文件或记录，因此升级时无需转换现有数据；文件在首个候选提出时创建。空文件缺失视为尚无命令。

文件写入采用同目录临时文件与原子 rename，权限为 `0600`。命令元数据不包含页面正文、截图或凭据。候选、成功试用次数、保留状态与时间戳保存在本机数据目录。用户可在 **设置 → Agent 与连接 → 站点命令** 保留已成功试用的候选或删除候选/已保留命令。

未知版本或结构无效时 Corvid 会拒绝读取并保留原始文件，不会降级或覆盖；用户应先备份该文件，再由对应版本恢复。删除 Room 不会把其命令转授给其他 Room；孤立命令仍保留原 Room ID，并可从设置列表删除。
